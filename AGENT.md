# AGENT.md

symbolhu: Tauri 2 + Vue 3 macOS desktop app that drills Hungarian-layout symbols (`< > * ( )` by default) on a MacBook keyboard.

## Commands

- `bun install`
- `bun run dev`: Vite only (browser; store falls back to localStorage)
- `bun run test`: vitest (pure logic only)
- `bun run build`: `vue-tsc --noEmit && vite build`
- `bun run tauri build --debug --bundles app`: native app at `src-tauri/target/debug/bundle/macos/symbolhu.app`
- `mkdir -p dist` before `cargo check` (`dist` is gitignored)

Run `bun run test` and `bun run build` before committing.

## Releases

Tag `vX.Y.Z` (matching `package.json`, `tauri.conf.json`, `Cargo.toml`) triggers `.github/workflows/release.yml`: arm64 `.dmg`, ad-hoc signed (`signingIdentity: "-"`), draft GitHub release. Not notarized; README documents the Gatekeeper workaround. Don't tag or publish without asking.

## Layout

- `src/engine/`: pure game logic, no Vue/Tauri imports. `rules.ts` (queue building, weakness), `session.ts` (`GameSession`), `settings.ts` (defaults and clamping). Each has a `.test.ts`.
- `src/input/match.ts`: classifies a `KeyboardEvent` as hit, miss or ignored.
- `src/layout.ts` + `src/data/layout-hu-mac.json`: char to physical key and modifiers. The JSON is generated by `scripts/gen-layout.swift`. Don't hand-edit it; rerun the script.
- `src/store.ts`: persistence via `tauri-plugin-store`, with localStorage fallback. Reads and writes are wrapped in `safe()` so a corrupt store never blocks the UI.
- `src/components/`: `Practice`, `Settings`, `Stats`, `KeyboardHint` (HTML/CSS, not SVG). `src/App.vue` wires them and saves data (fire-and-forget with `.catch`).
- `src-tauri/`: Rust shell, capabilities, config.
- `docs/superpowers/{specs,plans}/`: design spec and implementation plan.

## Game rules (user-confirmed; don't change without asking)

- A round asks every active char `hitsPerChar` (3) times, shuffled, with no immediate repeats.
- A wrong key or a timeout (3 s) is an immediate miss and shows the hint. The hint stays until the correct key is pressed; Esc skips it.
- A char with all hits in a round is mastered and dropped. The game ends when no chars remain or `maxRounds` (10) is reached.
- The next game picks the `gameSize` (5) weakest chars from the pool. Weakness is the miss rate over the last 30 asks; unseen = 0.5. With no history, use the default list.
- Quitting midway keeps per-char stats but records no game.
- Settings are clamped: timeout ≤60, hits ≤20, gameSize ≤50, rounds ≤100. Invalid values fall back to defaults.

## Gotchas

- Keep `tauri-plugin-store` pinned to 2.5.0 on both the npm and Rust sides.
- Hint combos: `<` is Shift+Option+Y-position key, `>` is Shift+Option+X-position key (physical codes on the Hungarian layout).
- The wrong-input-source banner triggers on a Y/Z swap.
- Dead keys may report `event.key === "Dead"` in WKWebView; the native behaviour is verified manually only, since macOS blocks UI automation of the window.
- Keep game logic in `src/engine/` so it stays unit-testable.
